# Система аренды транспорта для MTA:SA

Система аренды транспорта с поминутной оплатой, GUI интерфейсом и NPC менеджером.

## Особенности

- GUI интерфейс с управлением мышью и клавишами
- Поминутная оплата с автоматическим списанием
- Возврат 50% средств при досрочном возврате
- Защита от дублирования аренды и спама
- Управление стрелками, Enter, ESC
- Блип на карте
- NPC менеджер
- Случайный цвет машин

## Требования

- MTA:SA Server 1.5.0+
- Lua 5.1

## Установка

**1. Создайте папку ресурса**

Зайдите в папку сервера:
```server/mods/deathmatch/resources/```

Создайте там папку `rental_system`

**2. Скопируйте файлы**

Положите в `rental_system` следующие файлы:
- `client.lua`
- `server.lua`
- `config.lua`
- `meta.xml`


**3. Настройте координаты**

Откройте `config.lua` и измените координаты:

rentPoint = { x = 0.0, y = 0.0, z = 3.0 }   -- где стоит маркер и NPC
spawnPoint = { x = 5.0, y = 5.0, z = 3.0 }   -- где появляется машина

Как узнать координаты:
- Войдите в игру
- Встаньте в нужное место
- Ввести команду `/mesto` ( информация не точная, ласт раз работала в 2019 году )
- Ввести полученние координаты в config.lua

**4. Запустите ресурс**

Способ 1 - через консоль сервера:
- Откройте консоль (F8 если сервер локальный)
- Напишите: `start rental_system`

Способ 2 - через чат с правами администратора:
- Напишите в чат: `start rental_system`

Способ 3 - автозапуск при старте сервера:
- Откройте файл `mtaserver.conf`
- Добавьте строку: ` <resource src="rental_system" startup="1" protected="0" />`

**5. Проверьте работу**

- В игре на карте должен появиться зеленый круг (маркер)
- Если маркера нет, проверьте координаты в config.lua
- Подойдите к маркеру - должно открыться меню аренды

## Настройка

Полный пример config.lua:
```lua
local config = {
    rentPoint = { x = 2490.0, y = -1667.0, z = 13.0 },
    spawnPoint = { x = 2495.0, y = -1667.0, z = 13.0 },
    
    npcModel = 217,
    npcRotation = 180.0,

    vehicles = {
        { model = 411, name = "Infernus", pricePerMin = 50 },
        { model = 402, name = "Buffalo", pricePerMin = 40 },
        { model = 506, name = "Super GT", pricePerMin = 60 },
        { model = 560, name = "Sultan", pricePerMin = 30 },
        { model = 562, name = "Elegy", pricePerMin = 45 }
    },
    
    sounds = {
        start = "sounds/610609bad055b8b.mp3"
    }
}

return config
```

## Использование

**Для игроков:**

1. Найдите на карте зеленый маркер и подойдите к нему
2. Откроется меню со списком машин
3. Выберите машину (мышкой или стрелками ↑/↓)
4. Нажмите Enter или кнопку "АРЕНДОВАТЬ"
5. Деньги будут списываться каждую минуту автоматически
6. Чтобы вернуть машину, подойдите к маркеру и нажмите "ВЕРНУТЬ"
7. При возврате вернется 50% от остатка времени

**Управление в меню:**
- Стрелки ↑/↓ - навигация по списку
- Enter - арендовать выбранную машину
- ESC - закрыть меню
- Мышь - клик по кнопкам и списку

### client.lua
Клиентская часть: GUI интерфейс, маркер, обработка кликов и клавиш.

### server.lua
Серверная часть: логика аренды, списание денег, создание машин.

### config.lua
Конфигурация: координаты, список машин, настройки NPC.

## Решение проблем

**Ресурс не запускается**
- Проверьте, что все файлы на месте
- Проверьте синтаксис config.lua (нет ли лишних запятых)
- Посмотрите консоль сервера на наличие ошибок

**Не появляется маркер**
- Проверьте координаты в rentPoint
- Убедитесь, что координаты существуют (не под землей и не в стене)
- Попробуйте перезапустить ресурс

**Не создается машина**
- Проверьте координаты spawnPoint (должны быть на земле)
- Убедитесь, что ID модели машины существует
- Проверьте, свободно ли место для спавна

**Не списываются деньги**
- Убедитесь, что у игрока есть деньги на счету
- Проверьте, что таймер работает (нет ошибок в консоли)

**Ошибка "Config file not found"**
- Убедитесь, что config.lua находится в папке rental_system
- Проверьте права на чтение файла

## Советы

**Для новичков:**
- Сначала настройте только координаты и список машин
- Не добавляйте звуки, пока не убедитесь, что всё работает
- Тестируйте на локальном сервере перед запуском на публичном

**Для продвинутых:**
- Добавляйте больше машин в список vehicles
- Меняйте ID NPC на любой другой скин
- Настройте разные цены для разных машин
- Добавьте ограничение максимального времени аренды
